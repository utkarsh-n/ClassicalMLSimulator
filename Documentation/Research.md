# Classical ML Simulator: method references

References checked October 13, 2026. The native Swift implementation is an educational 2D simulator; it does not call scikit-learn or promise numerical parity with that library. The guide links below support the concepts, objective functions, and limitations used in the model catalog.

| Lab | Primary reference | Educational contract |
| --- | --- | --- |
| Linear regression | [scikit-learn: ordinary least squares and ridge](https://scikit-learn.org/stable/modules/linear_model.html#ridge-regression-and-classification), [LinearRegression reference](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LinearRegression.html) | Fit intercept and slope with full-batch gradient descent on MSE plus an L2 slope penalty (lambda 0.02 by default). The basis uses z = 2x - 1. This is regularized least squares, not the library's direct unpenalized solver. |
| Polynomial regression | [PolynomialFeatures reference](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.PolynomialFeatures.html), [polynomial regression guide](https://scikit-learn.org/stable/modules/linear_model.html#polynomial-regression-extending-linear-models-with-basis-functions) | Powers of z = 2x - 1 yield a curved function that remains linear in its weights. Full-batch descent includes an L2 penalty on all non-intercept weights. Degree can increase overfitting and instability outside the sampled range. |
| Logistic regression | [LogisticRegression reference](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html) | Binary sigmoid model with a linear boundary. A displayed class score is not evidence of calibration. |
| k-nearest neighbors | [scikit-learn: nearest neighbors classification](https://scikit-learn.org/stable/modules/neighbors.html#nearest-neighbors-classification) | Store training samples, query Euclidean neighbors, and use majority voting. Feature scale and k change the resulting regions. |
| Decision tree | [scikit-learn: decision trees](https://scikit-learn.org/stable/modules/tree.html) | Greedy axis-aligned classification splits use Gini impurity; depth controls complexity. The diagram describes the fitted tree rather than an exhaustive search over trees. |
| Random forest | [scikit-learn: random forests](https://scikit-learn.org/stable/modules/ensemble.html#random-forests-and-other-randomized-tree-ensembles) | Bootstrap samples and one randomly selected feature per node produce different trees. Average empirical leaf class probabilities and apply a 0.5 threshold; this is not a majority vote over hard tree labels. Those averages are not automatically calibrated posteriors. |
| Gradient boosting | [scikit-learn: gradient-boosted trees](https://scikit-learn.org/stable/modules/ensemble.html#gradient-boosted-trees) | Add weak learners sequentially along a loss-reducing direction. Learning rate and ensemble size interact. This lab uses binary logistic residuals and one-split decision stumps. |
| Gaussian naive Bayes | [scikit-learn: Gaussian naive Bayes](https://scikit-learn.org/stable/modules/naive_bayes.html#gaussian-naive-bayes) | Gaussian coordinate likelihoods and empirical class priors combine under conditional independence. Correlated features violate that assumption. |
| Linear SVM | [scikit-learn: SVM guide](https://scikit-learn.org/stable/modules/svm.html), [LinearSVC reference](https://scikit-learn.org/stable/modules/generated/sklearn.svm.LinearSVC.html) | Linear hinge-loss model with weight regularization. This pedagogical iterative solver is not LIBSVM/LIBLINEAR and has no RBF kernel. |
| k-means | [scikit-learn: k-means](https://scikit-learn.org/stable/modules/clustering.html#k-means) | Alternate nearest-center assignments and mean updates to reduce inertia. Cluster numbers are arbitrary identifiers, not known classes. |
| DBSCAN | [scikit-learn: DBSCAN](https://scikit-learn.org/stable/modules/clustering.html#dbscan), [DBSCAN API](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.DBSCAN.html) | Grow density-connected clusters using epsilon and minimum neighborhood size, including the point itself. Noise is a separate outcome; one global density threshold can fail on varying densities. |
| PCA | [scikit-learn: PCA](https://scikit-learn.org/stable/modules/decomposition.html#pca) | Center coordinates, identify dominant covariance eigenvectors, and project onto the first component. Component sign is arbitrary. High retained variance is not predictive accuracy. |
| Monte Carlo | [Metropolis: The Beginning of the Monte Carlo Method, Los Alamos Science, 1987](https://mcnp-green.lanl.gov/pdf_files/Article_1987_LAS_Metropolis_125--130.pdf), [Metropolis and Ulam: The Monte Carlo Method, 1949, DOI](https://doi.org/10.1080/01621459.1949.10483310) | Independent uniform area sampling estimates pi using hit fraction. This is a numerical sampling method, not a learned predictor, and this lab is not Markov chain Monte Carlo. |

## Reading the visualization

- The generated data is synthetic and dimensionless. Coordinates illustrate geometry; no real-world units or application claims are implied.
- In supervised labs, held-out points must not participate in fitting or neighbor voting. Training and held-out results measure different things.
- Clustering uses coordinates without their generated class labels. Comparing cluster identifiers directly with class identifiers would be invalid because the identifiers can be permuted.
- A playback step should represent the actual unit shown by that lab: optimization epoch, added tree, query, processed sample, or geometric stage. Animation speed is playback speed, not computation time.
- k-NN, Gaussian naive Bayes, and PCA reveal growing training batches. They do not simulate gradient updates or one query per playback step. Decision-tree frames compare fits at increasing depth limits.
- DBSCAN has no native held-out prediction rule. This lab explicitly extends fitted clusters to test/grid locations by assigning the nearest core point within epsilon; points outside that radius remain noise. It reports outside-radius fraction rather than predictive accuracy.
- Decision-region shading shows the model's current decision or score over a finite grid. Smooth shading does not establish calibrated uncertainty.
- A seed makes a run reproducible. Monte Carlo uses pseudorandom draws; finite runs can move away from pi before moving closer again. Typical sampling error scales as the inverse square root of sample count.

## Scope

The initial collection covers 13 common classical methods and related numerical tools. It is not an exhaustive list of machine learning algorithms. The catalog names the concrete variants (binary logistic, Gaussian naive Bayes, and linear SVM), and each lab states assumptions and failure modes so users can compare behavior rather than interpret a visually attractive fit as general validity.
